# Life Quest — PRD (Product Requirements Document)

## 1. 서비스 개요

Life Quest는 현실의 다양한 경험을 게임의 퀘스트로 바꿔, 사용자가 매일 새로운 퀘스트를 수행하며 경험치·레벨·도감·업적을 쌓아가는 **현실 RPG 플랫폼**이다.

기존 습관 관리 앱은 사용자가 목표를 직접 정하고 반복 체크해야 해서 쉽게 흥미를 잃는다. Life Quest는 시스템이 매일 퀘스트를 제시하고 사용자는 수행만 하면 되는 구조로 진입 장벽을 낮춘다.

## 2. 해결하려는 문제

- 반복되는 일상, 새로운 경험을 시작하기 어려움
- 외출·다양한 활동 부족
- 목표를 꾸준히 유지하기 어려움

## 3. 대상 사용자

- 새로운 경험을 원하지만 계기가 부족한 20~30대
- 기존 습관 관리 앱에 쉽게 흥미를 잃은 사용자
- 친구와 비교·경쟁하며 동기부여를 받는 사용자

### 4-1. 제외 (Phase 2 — 발표 로드맵으로만 소개)

시즌 이벤트 · NPC 스토리 · 길드(파티) · AI 기반 퀘스트 추천 · 협동 퀘스트(동행 매칭) · 성향 기반 자동 분기 · AR.

> 확장 아키텍처(4엔진: 배정·성향·파생·매칭)의 상세 설계는 `docs/life-quest-design.html` 참조. 이 PRD는 **4주 MVP 스코프만** 다룬다.

## 5. 성공 기준

- 위 10개 MVP 기능이 **배포 가능한 완성도**로 동작한다(미완성·버그 없음 — 최우선 기준).
- 로그인 → 오늘의 퀘스트 → (필요 시 GPS 인증) → 완료 → EXP/레벨업 → 도감/업적 반영 → 랭킹 갱신, 핵심 플로우가 끊김없이 연결된다.
- 퀘스트 콘텐츠 일부가 공공데이터(TourAPI/문화포털)로 채워져 있다.
- 동일 퀘스트를 중복 완료해도 EXP·업적이 오염되지 않는다(멱등성 — [[business-rules.md]] §4).
