# Life Quest — PRD (Product Requirements Document)

## 1. 서비스 개요

**Life Quest**는 현실을 게임처럼 즐기고, 경험을 수집하며 성장하는 **라이프 RPG 플랫폼**이다.

사용자가 현실 속 다양한 활동을 게임의 퀘스트처럼 수행하며 경험치(EXP)를 획득하고, 레벨업과 도감 수집, 업적 달성을 통해 지속적으로 새로운 경험을 하도록 돕는 게임형 라이프스타일 서비스다.

## 2. 배경 · 해결하려는 문제

현대인은 반복되는 일상 속에서 새로운 경험을 시도할 기회가 적고, 기존 습관 관리 앱은 사용자가 직접 목표를 설정하고 반복 체크해야 하므로 흥미를 유지하기 어렵다. Life Quest는 **시스템이 매일 퀘스트를 제시하고 사용자는 수행만 하면 되는 구조**로 진입 장벽을 낮춘다.

- 반복되는 일상으로 인한 새로운 경험 부족
- 새로운 활동을 시작하기 어려움
- 외출 및 다양한 문화생활 부족
- 목표를 꾸준히 이어가기 어려움
- 기존 습관 관리 앱의 낮은 지속성

→ **현실을 게임처럼 즐기며 자연스럽게 다양한 경험을 할 수 있도록 한다.**

## 3. 서비스 목표

- 현실 속 다양한 경험을 게임 콘텐츠로 제공
- 사용자의 지속적인 참여와 동기부여 제공
- 경험을 수집하고 기록하는 새로운 라이프 플랫폼 구축
- 게임 요소를 활용하여 자기계발을 재미있게 만드는 서비스 구현

## 4. 대상 사용자

- 새로운 경험을 원하지만 계기가 부족한 20~30대
- 기존 습관 관리 앱에 쉽게 흥미를 잃은 사용자
- 친구와 비교·경쟁하며 동기부여를 받는 사용자
- 수집(도감·업적·칭호)에 재미를 느끼는 사용자

## 5. 핵심 컨셉

**현실 속 행동 = 게임 퀘스트.** 사용자는 현실에서 다양한 활동을 수행하며 게임처럼 성장한다.

예시 퀘스트: ☕ 새로운 카페 방문 · 🚶 30분 산책 · 🍜 새로운 음식 먹기 · 📞 부모님께 전화 · 📸 공원에서 사진 찍기

핵심 루프:

```
퀘스트 완료 → EXP 획득 → 레벨업 → 도감 등록 → 업적 달성 → 새로운 콘텐츠 해금 → (반복)
```

퀘스트마다 희귀도(⚪ 일반 · 🔵 희귀 · 🟣 영웅 · 🟠 전설)가 있으며, 등급이 높을수록 보상이 크다 — [비즈니스 규칙서](./business-rules.md) §4.

## 6. MVP 범위

프로젝트 기간(4주) 내 실제 구현 대상. 담당은 예시 배분이며 팀 협의로 조정 가능하다.

| # | 기능 | 설명 | 담당 |
|---|---|---|---|
| 1 | 회원가입 / 로그인 (JWT) | 이메일 가입 · JWT 발급 | 팀원1 |
| 2 | 오늘의 퀘스트 제공 | 매일 랜덤 배정 · 난이도(등급)별 보상 차등 | 팀원1 · 팀원2 |
| 3 | 퀘스트 완료 · EXP 지급 | 완료 처리 트랜잭션 · 멱등 처리 | 팀원2 |
| 4 | 레벨 시스템 | 누적 EXP 기반 레벨업 · 레벨업 보상 지급 | 팀원3 |
| 5 | 경험 도감 (LifeDex) | 카테고리별 경험 항목 수집 · 진행률 | 팀원3 |
| 6 | 업적 시스템 | 단계형 업적(I~V) · 칭호 해금 | 팀원3 |
| 7 | 친구 랭킹 | 친구 추가 · 주간 EXP 랭킹 · 업적 비교 | 팀원4 |
| 8 | 마이페이지 | 프로필 꾸미기(테두리·배경·배지) · 대표 칭호/업적 | 팀원4 |

### 6-1. 제외 — Phase 2 (발표 로드맵으로만 소개)

기획서의 주요 기능 중 MVP에 포함하지 않는 항목:

- **랜덤 보물상자** — 완료 응답에 확장 필드로 훅만 예약([API 명세서](./api-spec.md) §3)
- **비밀 업적** — 업적 테이블에 `hidden` 플래그만 예약
- **지역 해금** · **위치 기반 지역 미션**(GPS 인증 포함)
- **시즌 이벤트** · **랜덤 이벤트**(Lucky Day 등) · **스토리 시스템**(Chapter)
- AI 기반 개인 맞춤 퀘스트 추천 · 날씨/계절 연동 퀘스트 · 협동 퀘스트 · 길드 시스템 · NPC 스토리 및 세계관 · 오프라인 이벤트 연동

> MVP의 퀘스트 완료 인증은 **셀프 체크(완료 버튼)** 방식이다. GPS·사진 등 인증 강화는 Phase 2 — [비즈니스 규칙서](./business-rules.md) §3.

## 7. 차별화 요소

| 기존 습관 관리 앱 | Life Quest |
|---|---|
| 해야 할 일 체크 | 현실을 RPG처럼 플레이 |
| 반복적인 목표 관리 | 매일 새로운 경험 제공 |
| 단순 기록 | 경험 수집 및 도감(LifeDex) |
| 꾸미기 요소 부족 | 레벨 · 칭호 · 배지 · 프로필 꾸미기 |
| 경쟁 요소 부족 | 친구 랭킹 · 업적 비교 |
| 콘텐츠 확장 제한 | 등급 콘텐츠 해금, (Phase 2) 지역 해금 · 시즌 |

## 8. 성공 기준

- 위 8개 MVP 기능이 **배포 가능한 완성도**로 동작한다(미완성·버그 없음 — 최우선 기준).
- 핵심 플로우가 끊김없이 연결된다: 회원가입/로그인 → 오늘의 퀘스트 확인 → 완료 → EXP 획득 → 레벨업/보상 → 도감 등록 → 업적 달성 → 랭킹 갱신.
- 동일 퀘스트를 중복 완료 요청해도 EXP·업적·도감이 오염되지 않는다(멱등성 — [비즈니스 규칙서](./business-rules.md) §3).
- 퀘스트·도감 시드 데이터가 시연 가능한 수준(카테고리 5종 이상, 퀘스트 30개 이상 `[예시]`)으로 준비되어 있다.

## 11. 기대 효과

- 게임 요소를 활용한 지속적인 동기부여

- 현실과 게임을 연결한 새로운 경험 플랫폼 구축
