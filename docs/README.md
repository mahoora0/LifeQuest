## MVP 스코프 (4주)

회원가입/로그인(JWT) · 오늘의 퀘스트 · 퀘스트 완료/EXP · 레벨 시스템 · 경험 도감(LifeDex) · 업적 시스템 · 친구 랭킹 · 마이페이지(프로필 꾸미기).

**Phase 2 (향후 확장)**: 랜덤 보물상자 · 비밀 업적 · 지역 해금 · 위치 기반 미션(GPS) · 시즌/랜덤 이벤트 · 스토리 · AI 맞춤 추천 · 날씨/계절 연동 · 협동 퀘스트 · 길드 · NPC 세계관 · 오프라인 이벤트 — [PRD](./PRD.md) §6-1.
