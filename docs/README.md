## 확장 설계 (Phase 2 컨셉 자료)

- **`life-quest-design-preview.png`** — 전체 페이지 미리보기. GitHub에서 바로 열람 가능(오프라인 OK).
- **`life-quest-design.html`** — 인터랙티브 원본. 브라우저로 열면 다이어그램까지 렌더.
- 담은 내용: 4엔진 확장 아키텍처(배정·성향·파생·동행 매칭), 공공데이터(TourAPI·문화포털), 발표 스크립트. **위 기획 문서의 MVP 범위보다 넓은 비전 자료** — 실제 4주 구현은 기획 문서 기준.

## MVP 스코프 (4주)

로그인 · 오늘의 퀘스트 · GPS 위치 인증 · 완료/EXP · 레벨업 · 도감 · 업적 · 친구 랭킹 · 프로필.
시즌·NPC·길드·AI 추천·동행 매칭(자동)·성향 기반 자동 분기·AR = **향후 확장**(발표 로드맵, [PRD](./PRD.md) §4-1).
