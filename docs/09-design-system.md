# 09. 디자인 시스템과 화면 구성 규칙

> 관련 문서: `02-screen-spec.md` · `04-api-spec.md` · `05-business-rules.md`

## 1. 토큰 — 하드코딩 금지 목록

아래 값은 모두 `app/lib/shared/design/lq_tokens.dart`에 있다.
화면·위젯 코드에 색과 치수를 직접 쓰지 않는다.

### 1-1. 표면 3단

| 역할 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `surfacePanel` | `#FFFDF6` | Scaffold 바탕 · 프레임 · 리스트 행 |
| `surfaceCard` | `#FBF4E4` | 주 콘텐츠 카드 — 프레임보다 한 단계 눌러 담아 깊이를 만든다 |

**규칙** — 한 화면에 크림 계열 배경은 1~2단계만. 원색·순백·순흑을 쓰지 않는다.
카드 안에 카드를 넣을 때는 안쪽을 `surfacePanel`로 되돌려 대비를 만든다.

### 1-2. 잉크 · 브랜드 · 상태

- **잉크** `#4A4132`(모든 테두리) · 본문 `#443B2A` / `#5C5344` · 보조 `#7A7060` · 흐린 `#9A8F7B` · 어두운 면 위 글자 `#FEF8EE`
- **브랜드 그린** — 주 액션 `#55663D`, 탭 활성 `#4A6B2F`, EXP 채움 `#7A8B54`, EXP 뱃지 `#5A6B3B`
- **보상 골드** — `#E7B94F`(재화·메달), 연한 `#F1DFAE` + 테두리 `#C9A94E` + 글자 `#5C4A22`, 도장 `#A8842B`
- **강조 테라코타** `#C96A47` — 알림 점, 파괴적 액션, 펄스 링. 남용 금지
- **상태** — 성공 `#55663D`/`#E9EFDC` · 주의 `#A8652B`/`#F6E7D4` · 위험 `#9A4B33`/`#F3DBD3`

### 1-3. 타이포 — 크기와 굵기로만 위계를 만든다

전 텍스트 **에이투지체(A2Z)** 단일 — SIL OFL, `app/assets/fonts/`에 번들되며 `ThemeData.fontFamily`로 일괄 적용된다. 굵기는 400 / 700 두 단계뿐이고(테마 기본값이 쓰는 500 포함 3종만 번들), 위젯에서 `fontFamily`를 지정하지 않는다(테마 글꼴을 덮어쓴다).

`30` displayTitle · `25` bigTitle · `24` levelNumber · `21` sectionTitle · `20` screenTitle · `16.5` cardTitle · `16` body · `15` bodySm · `14` label · `13.5` caption · `11.5` tabLabel(최소) · `11` badge

### 1-4. 형태 — 비대칭 라운드가 정체성

네 모서리 값이 조금씩 다르다. 완전 대칭은 pill(99)뿐이다.

| 대상 | 라운드 |
|---|---|
| 프레임 · 폰 | 26 / 30 / 26 / 30 |
| 카드 | 16 / 20 / 16 / 20 |
| 리스트 행 | 14 / 17 / 14 / 17 |
| 버튼 | 14 / 18 / 14 / 18 |
| 타일 | 12 / 15 / 12 / 15 |
| 아이콘 웰 | 10 / 13 / 10 / 13 |

테두리는 거의 모든 컨테이너에 **2px solid** 잉크. 잠김·비활성·안내는 **2px dashed** `#C9BC9E`.

그림자는 블러 0 오프셋 판화다. 카드 `4px 5px 0 rgba(90,70,40,.12)` · 버튼 `3px 4px 0 rgba(90,70,40,.25)` · 모달 `5px 6px 0 rgba(40,32,18,.3)`. **부드러운 블러 그림자 금지.**

### 1-5. 여백 · 치수

화면 좌우 패딩 **16** · 섹션 gap **12** · 진행 바 높이 **12** · 최소 터치 타깃 **44**.
프레임 기준 **360×800**(시안 원본 320×680에서 확대, 카드 수는 늘리지 않는다).

## 2. 컴포넌트 — 새로 만들지 말고 조합할 것

| 컴포넌트 | 규칙 |
|---|---|
| `LqCard` | `header`를 주면 제목 띠(패딩 5/14, 하단 ink 2px 실선)가 붙고 본문에만 패딩이 적용된다. `headerTrailing`은 "더보기 ›" 같은 보조 요소. `locked`는 점선 + `lockedBg` + 그림자 없음. **좌측 컬러 보더 액센트 금지.** 제목·보조 요소는 모두 축약(ellipsis)되므로 닉네임 같은 사용자 입력을 넣어도 넘치지 않는다 |
| `LqButton` | 높이 50, 풀폭. 비활성은 `#E3DCC8` 배경 + `textMuted` 글자 + **그림자 없음**. 진행 중에는 스피너로 중복 탭을 막는다. 나란히 놓인 보조·파괴적 액션은 `borderColor: borderMuted` + `shadow: false`로 한 단계 뒤로 물린다 |
| `LqChip` / `LqChipRow` | 선택 = primary 배경 + ink 테두리 + 흰 글자. 미선택 = raised + borderMuted. 행 높이 44로 터치 타깃을 확보한다 |
| `LqRewardBadge` | EXP는 `expBadge` 채움, 골드는 `goldBg` + `goldBorder`, 위치는 `locBg` + `locBorder`. 주기 태그(일간·주간)와 위치 뱃지는 **별개의 축**이라 함께 붙는다 |
| `LqProgressBar` | 높이 12, ink 2px, pill. 값이 바뀌면 500ms ease-out로 애니메이션한다. 작은 자리에서는 높이 9 + 테두리 1.6 |
| `QuestCheckButton` | 원형 27, 완료 시 `expBadge` 배경 + ✓. 44 터치 타깃 안에 넣는다. **위치 퀘스트에는 쓰지 않고** ›로 상세로 보낸다 |
| `LqStatusBanner` | GPS 인증 상태 표시 전용. tone에 따라 배경·테두리·글자가 한 세트로 바뀐다(테두리 색 = 글자 색) |
| `LqStamp` | 기울어진 도장(−6°). 업적 완료와 LEVEL UP에만 쓴다 |
| `LqDashedDivider` | 구분선을 그릴 때는 **실선을 쓰지 않는다** — 가로도 세로도 이 위젯이며, 세로는 `axis: Axis.vertical`. 다만 **행이 각자 테두리를 갖는 목록에는 구분선을 두지 않는다**(홈 오늘의 퀘스트): 테두리와 구분선이 겹쳐 경계가 두 번 그려진다. 그 목록은 행 사이를 간격 8로만 벌린다 |
| `LqSpeck` | 둥실 떠다니는 장식(`lqFloat`). 이 위젯이 든 화면은 애니메이션이 끝나지 않으므로 위젯 테스트에서 `pumpAndSettle()` 대신 `pump()`를 쓴다 |
| `LqBottomNav` | 홈 · 퀘스트 · 지도 · 친구 · 마이. 아이콘 20 + 라벨 11.5, 상하 패딩 8/10, 상단 ink 2px. **탭을 늘리지 않는다** |

**아이콘** — 아이콘 폰트와 이모지를 쓰지 않는다. 선 아이콘은 stroke 2.2 · round cap · 24 그리드 SVG이며 `app/assets/images/icons/`에 있다(`LqIcons` 상수 → `LqIcon` 위젯). 그중 `home` · `quest` · `map` · `friends` · `my` 5종이 하단 탭이고, `search`는 동료 찾기 입력에, `lifedex`는 아직 쓰는 곳이 없다. 그 외 기호는 텍스트 글리프(**← › ✓ + ? ×**)로 취급한다. 새 아이콘이 필요하면 같은 규격의 Lucide 아이콘을 stroke 2.2로 맞춰 같은 디렉터리에 추가한다.

**일러스트** — 캐릭터 PNG 6종(front · wave · sit · walk · map · plain-sit)과 아이콘 PNG 3종(flag · backpack · map). 빈 상태·축하·안내에 적극적으로 쓴다. **SVG로 캐릭터를 직접 그리지 않는다.**

## 3. 레이아웃 규칙

- **화면 골격** — `Scaffold(surfacePanel)` › `SafeArea(bottom: false)` › 헤더 › 본문. 탭 루트 화면은 `showBack: false`, push 화면은 좌상단 ←
- **스크롤** — 카드가 3개를 넘는 화면(마이페이지는 8개)은 `ListView`로 감싸고 **어떤 카드에도 `Expanded`/`Flexible`을 주지 않는다.** 자연 높이를 잃으면 스크롤 대신 카드가 잘려 보인다
- **헤더는 본문과 분리** — 조회 실패·준비 중 화면에서도 헤더는 남아야 한다. 탭 밖 push 화면에서 헤더까지 사라지면 돌아갈 길이 없다(탭바도 없음)
- **헤더 보조 버튼은 폭을 글자에 맞춘다** — 헤더는 `Stack`이라 `Container`에 `alignment`를 주면 화면 폭까지 커져 제목과 뒤로 가기를 덮는다. `SizedBox` + `Center(widthFactor: 1)`을 쓴다
- **고정 높이 자리** — 카드 안의 로딩·빈·오류는 카드 높이를 흔들지 않도록 일정한 높이(예: 홈의 오늘의 퀘스트 250, 도감 항목 그리드 240)를 차지한다
- **애니메이션** — 바운스 이징 `cubic-bezier(.2,.8,.3,1.2)`, 0.5~0.6s. 장식은 `lqFloat`(둥실), 위치 표시는 `lqPulse`(파동, 1.8~2s). 그 외 전환은 넣지 않는다

## 4. 카피 규칙

사용자는 언제나 **모험가님**. 다정한 동료의 해요체로 권유하고 명령하지 않는다.
한 줄 12~18자, 최대 2줄. 느낌표는 축하·격려에만. **이모지 금지.**

**RPG 어휘를 섞지 않는다** — 퀘스트 / 모험가 / EXP / 도감(LifeDex) / 탐험도 / 칭호 / 업적 / 보상 / 원정 / 동료. 현실 어휘(할 일, 태스크, 미션, 친구 추가, 수락)는 쓰지 않는다. "수락"을 **함께하기**로, "친구 검색"을 **동료 찾기**로 쓴 것이 그 예다.

**실패도 긍정형으로**

| 쓴다 | 쓰지 않는다 |
|---|---|
| 아직 반경 밖이에요 — 조금 더 가까이! | 인증 실패 |
| 아직 순위에 없어요 | 데이터 없음 |
| 준비 중이에요 | 오류 |

**숫자** — 통화 기호 없이 `G 15`, `EXP 40`. 네 자리 이상은 천 단위 콤마(`1,250`).

## 5. 상태 4종 — 어떤 것을 언제

| 상태 | 조건 | 모습 | 재시도 버튼 |
|---|---|---|---|
| 로딩 | 값이 아직 없음 | char-walk 92 + 스피너 + "불러오는 중이에요…" | 없음 |
| 빈 | 값은 왔고 비어 있음 | char-sit 118 + 화면별 문구 | 없음 |
| 오류 | 조회 실패(재시도 의미 있음) | char-sit 108 + 오류 문구 | **있음** (폭 180) |
| 준비 중 | 서버 엔드포인트 미개설 | "…은 아직 준비 중이에요" + 대안 안내 | **없음** — 눌러도 결과가 같아 헛돌게 됨 |

**준비 중 판정은 상태 코드가 아니라 서버 코드로 한다.** 매핑된 컨트롤러가 없는 경로에 백엔드가 `404 ENDPOINT_NOT_FOUND`를 붙여 보내며, `isFeatureNotReady()`가 그 코드로 판정한다. 대상만 없는 `RESOURCE_NOT_FOUND`는 엔드포인트가 살아 있는 경우라 오류로 남긴다.

**준비 중 화면을 만들 때는 `LqAsyncView`에 `notReadyMessage`를 반드시 준다.** 주지 않으면 오류 분기로 떨어져 "준비 중"이라고 말하면서 재시도 버튼을 다는 상태가 된다.

**새로고침 중에는 직전 데이터를 유지**한다. 값이 있으면 상태 화면으로 갈아끼우지 않는다(깜빡임 방지). 한 화면에 여러 조회가 있으면 개별 실패는 그 카드만 오류로 표시하고, 당김-새로고침 제스처 자체는 깨지지 않게 삼킨다.

**진입점은 상태 분기 밖에 둔다.** 다른 화면으로 가는 유일한 문(알림 설정 카드, 받은 요청 배너 등)을 조회 결과 안에 넣으면 빈 상태·준비 중·오류에서 함께 사라진다.

## 6. 서버가 아직 없는 구간

서버가 열리지 않은 구간은 화면 검토용 표본으로 그린다. 표본 없이 없는 엔드포인트를 호출하면 화면이 늘 오류 상태로만 보여 레이아웃·상호작용을 검토할 수 없다.

표본은 **명시적으로 켰을 때만** 나오며 기본값은 꺼짐이다.

```
dart run tool/run_app.dart                  # 런처가 플래그를 넣어 준다
flutter run --dart-define=LQ_SAMPLES=true   # 직접 켤 때
flutter build apk                           # 플래그 없음 → 표본 없음
```

- 빌드 모드(`kDebugMode`)에 묶지 않는다. CI의 Android job이 `flutter build apk --debug`로 산출물을 만들기 때문에, 디버그 기준으로 두면 배포되는 APK가 표본을 실데이터처럼 보여준다
- 부를 엔드포인트 자체가 없는 구간은 `LqSampleData.guard()`
- 호출할 경로가 있는 구간은 `LqSampleData.orSample()` — 서버가 그 경로를 열면 표본은 저절로 물러난다
- 남은 호출부는 `rg 'LqSampleData'`로 찾는다

## 7. 상세 플로우

### 7-1. 진입

`/splash`에서 토큰을 확인한다. 세션 없음 → `/login`, 세션 있음 → `/`.
로그인·회원가입만 비로그인 접근이 가능하고 나머지는 전부 `/login`으로 리다이렉트된다.

### 7-2. 퀘스트 완료 — 두 갈래

- **직접 완료(SELF_REPORT)** — 홈 또는 상세에서 바로 완료 호출 → 완료 결과로 이동. 홈에서는 `push`, 상세에서는 `pushReplacement`(뒤로 가면 목록으로 돌아가야 하므로)
- **위치 인증(LOCATION)** — 상세 → 위치 인증 화면 → 반경 안에서만 완료 호출 → 성공 모달 → 완료 결과(`pushReplacement`)

완료 요청 중에는 해당 행을 `busy`로 잠가 중복 탭을 막고, 실패하면 서버 상태로 되돌린다(낙관적 갱신을 남겨두지 않는다).

**완료와 만료는 둘 다 누를 수 없지만 다르게 그린다.** 완료는 선명한 채로 제목에 취소선을 긋고 체크를 `expBadge`로 채운다. 만료는 행 전체를 `opacity .55`로 물리고 `만료` 뱃지를 붙인다. 누를 수 없다는 이유로 둘을 같이 흐리면 해낸 일과 놓친 일의 구분이 사라진다.

**낙관적 갱신의 롤백은 그 항목만 되돌린다.** 요청 전 목록을 통째로 복원하면 기다리는 동안 성공한 다른 동작까지 지워진다.

### 7-3. GPS 인증 상태 머신 (S-10)

| 상태 | 배너 tone | 문구 | CTA |
|---|---|---|---|
| locating | neutral | 내 위치를 찾는 중… | 비활성 · 내 위치를 찾는 중… |
| lowAccuracy | warn | 위치 정확도가 낮아요 — 잠시 후 다시 | 비활성 · 자동 재시도 |
| outOfRadius | warn | 아직 반경 밖이에요 — 조금 더 가까이! | 비활성 · 반경 안에서 인증할 수 있어요 |
| **inRadius** | success | 반경 안이에요! 인증할 수 있어요 | **활성 · 현재 위치로 인증하기** |
| permissionDenied | danger | 위치 권한이 꺼져 있어요 | 위치 권한 허용하기 |
| serviceDisabled | danger | GPS가 꺼져 있어요 | 위치 설정 열기 |
| missingTarget | danger | 이 퀘스트에는 인증 좌표가 없어요 | 비활성 |
| failed | danger | 위치를 받아오지 못했어요 | 다시 시도 |

**판정 권한은 서버에 있다.** 클라이언트 계산은 안내용이다. 서버가 `OUT_OF_RADIUS` / `LOCATION_ACCURACY_TOO_LOW`로 거절하면 **거절받은 좌표를 함께 기억**해 두고, 그 지점에서 GPS 흔들림(`max(15m, accuracy)`)보다 크게 움직였을 때만 배너를 해제한다. 그렇지 않으면 다음 위치 틱이 클라이언트 계산으로 덮어써서 거절이 사라지고 무한 재시도가 된다.

반경을 서버가 주지 않으면 **추측하지 않고** "인증 반경은 서버가 확인해요"로 표시한다. 실기기 없이 흐름을 확인할 수 있게 `kDebugMode` 한정 좌표 시뮬레이터(실제 GPS / 반경 안 / 반경 밖 / 권한 거부)를 둔다.

### 7-4. 완료 결과 분기 (S-12)

완료 응답을 `extra`로 받아 그대로 렌더링한다(재조회 없음). 분기는 셋이다.

- **일반** — 도장 카드 + 캐릭터 + 보상. 컨페티 4조각이 떠다닌다
- **레벨업** — 위 화면에 LEVEL UP 패널(Lv.N → Lv.N+1 + 받은 칭호·아이템)을 더한다
- **중복(`duplicated`)** — 멱등 재요청이라 보상이 재지급되지 않는다. **컨페티를 띄우지 않고** 안내만 남긴다

신규 도감·업적은 각각 점선 카드 한 줄로 알린다. 비밀 업적 해금(S-17)은 목록에 묻히면 놓치므로 **완료 결과 위에 모달로 겹친다.** 모달이 맡은 항목은 목록 줄에서 뺀다.

### 7-5. 대표 칭호 · 대표 배지 — 지정은 한 곳에서만

지정은 **업적 화면의 칭호·배지 탭에서만** 한다. 마이페이지의 "내 배지" 카드는 미리보기와 "더보기 ›" 진입만 맡는다 — 지정 로직이 두 곳에 생기면 낙관적 갱신과 롤백을 양쪽에서 관리해야 한다.

지정 결과는 **반드시 보이는 곳에 반영**한다 — 마이페이지 헤더의 대표 배지 표식, 그리고 미리보기 4칸의 **첫 칸으로 끌어옴**. 다섯 번째 배지를 대표로 지정했는데 미리보기가 그대로면 지정이 먹혔는지 알 수 없다. 같은 항목을 다시 누르면 해제된다.

### 7-6. 친구 · 랭킹

한 화면에서 세그먼트 2개(친구 목록 / 이번 주 랭킹)로 전환한다. 친구가 없어도 **빈 상태로 갈아끼우지 않는다** — 친구가 없을수록 하단의 친구 코드 카드가 필요하다.

응원은 되돌릴 수 없는 단방향이라 누른 뒤에는 골드 채움 + "응원함 ✓" 비활성으로 남는다. 행 전체가 동료의 여정으로 가는 문이므로 **응원 버튼은 탭을 삼킨다**(이미 응원한 상태에서도).

지난주 집계가 없으면 등락 pill을 **만들어내지 않고 감춘다.** 본인 행은 배경 `#F3E4C8` + ink 테두리로 강조한다(다른 행은 `#D8CDB4`).

받은 요청은 상태가 아니라 **처리할 일**이라 세그먼트가 아닌 배너로 띄운다. 거절은 조용히 처리한다 — 상대에게 알리지 않고, 같은 사람이 다시 요청할 수 있게 둔다.

## 8. 위치 권한 안내 — 2단계

한 번에 묻고 끝내지 않고 **두 단계로 나눠** 요청한다. 1단계는 **왜 필요한지**를 설명하고, 2단계는 **지금 필요하다**고 요청한다. OS 권한 팝업은 사용자가 "허용하기"를 누른 뒤에만 띄운다 — 설명 없이 먼저 띄우면 영구 거부(`deniedForever`)로 굳어 되돌릴 방법이 설정 앱뿐이 된다.

| 단계 | 언제 | 무엇을 |
|---|---|---|
| **1 · 전면 안내** | 가입·로그인 직후 첫 실행 | 현장 인증과 주변 탐색 두 가지 쓰임을 설명하고 "이동 경로는 저장하지 않는다"를 함께 밝힌다 |
| **2 · 배너 + 시트** | 권한이 없는 상태에서 **위치 퀘스트를 실제로 열 때** | 홈 배너는 상시 남기고, 바텀 시트는 **위치 퀘스트를 눌렀을 때만** 올린다 |

**재노출 규칙**

1. 1단계에서 **"나중에 할게요"**를 누르면 그날 다시 띄우지 않는다. 그 사이에는 2단계(배너·시트)만 동작한다
2. 날짜가 바뀌면 다음 실행 때 1단계를 **한 번 더** 보여준다 — 첫날엔 필요를 못 느꼈다가 위치 퀘스트를 받고 나서 생각이 바뀌는 경우가 흔하다
3. **OS 팝업을 거절한 경우에도 미룬 것으로 기록한다.** 기록하지 않으면 매 실행 전면 안내가 다시 떠, 부드럽게 넘긴 사람보다 거절한 사람이 더 자주 보게 된다
4. "하루"는 24시간 경과가 아니라 **날짜 경계**로 세되, 그 경계는 자정이 아니라 **04:00**이다(`05-business-rules.md` §1-1의 논리적 일자와 같은 규칙). 전면 안내는 앱 실행당 한 번만 띄운다
5. 권한을 **허용하면 두 단계 모두 영구히 사라진다.** 홈 배너도 함께 걷고 미룬 기록도 지운다
6. OS가 `deniedForever`를 돌려주면 시트의 CTA를 **"설정에서 켜기"**로 바꾸고 앱 설정을 연다 — 같은 버튼으로 다시 요청해도 팝업이 뜨지 않아 사용자가 헛돈다. 이 상태에서 "지금은 넘어가기"를 눌러도 단계를 낮추지 않는다(낮추면 복구 경로를 잃는다)
7. 미룬 날짜는 서버가 아니라 **로컬에 저장**한다(`SharedPreferences`). 기기별 권한 상태라 계정을 따라다닐 값이 아니다

규칙 4의 경계가 자정이었을 때는 밤 11시에 미룬 사용자가 자정을 넘겨 앱을 다시 켜면 안내를 한 번 더 보게 됐다. 경계를 04:00으로 옮기면 23:00과 다음날 01:00이 같은 날이 되어, "미룬 뒤 최소 N시간" 같은 장치를 따로 두지 않고도 막힌다.

## 11. 진입점 원칙

사용자가 찾아 들어가는 화면은 **진입점 1개**로 둔다(계층이 분명해진다). 여러 문맥에서 같은 대상을 열 때만 2~3개를 허용한다(퀘스트 상세 — 홈 행 · 목록 행 · 지도 요약 카드).

**같은 부모 아래 형제 화면끼리 서로를 여는 문은 만들지 않는다.** 도감과 업적은 둘 다 마이페이지 "나의 기록" 아래에 있으므로 도감에서 업적으로 건너가지 않는다.

**눌러도 아무 일이 없는 요소는 "고장"으로 읽힌다.** 연결하거나 지운다. 목록이 3~8개인 화면에 검색을 두면 데이터가 더 많아 보이는 오해를 주므로 두지 않는다.

현재 배선은 다음과 같다.

| 화면 | 진입점 |
|---|---|
| 홈 · 퀘스트 · 지도 · 친구 · 마이 | 하단 탭 |
| S-05 레벨 · 보상 | 마이페이지 EXP 바(› 표식) |
| S-18 동료 찾기 | 친구 헤더 **+** · 친구 코드 카드 **›** |
| S-19 받은 요청 | 친구 목록 상단 배너(요청이 있을 때만) |
| S-21 동료 여정 비교 | 친구 행 · 랭킹 행 전체 탭 |
| S-17 비밀 업적 해금 | 완료 응답의 `newAchievements` — 사용자가 여는 화면이 아니라 사건 |
| 알림 목록 · 설정 | 홈 헤더 알림 벨 · 마이페이지 "알림 설정" |
| S-04 프로필 수정 | 마이 헤더 "변경" pill · 설정 리스트 행(문맥이 달라 2개를 유지) |
| S-23 관리자 콘솔 | 웹 별도 URL — 앱에 진입점을 만들지 않는다 |

알림 벨의 점은 **읽지 않은 알림이 실제로 있을 때만** 찍는다. 늘 켜 두면 표식이 뜻을 잃는다.

## 12. 새 화면을 만들 때 체크리스트

1. 색·치수를 `lq_tokens.dart`에서만 가져왔는가
2. 탭 루트인가 push인가 — push면 좌상단 ←가 있고 탭바가 숨는가
3. 로딩 · 빈 · 오류 · 준비 중 4상태를 모두 정의했는가 (준비 중에는 `notReadyMessage`를 주고 재시도 버튼을 붙이지 않았는가)
4. 다른 화면으로 가는 유일한 진입점을 상태 분기 **밖**에 뒀는가
5. 카드가 3개 이상이면 `ListView`이고 `Expanded`를 쓰지 않았는가
6. 모든 탭 대상이 44 이상인가 (칩·체크·아이콘 버튼은 래퍼로 확보)
7. 새 컴포넌트를 만들지 않고 기존 `Lq*` 조합으로 끝냈는가
8. 카피가 해요체 · 모험가님 · RPG 어휘이고, 실패도 긍정형인가
9. 아이콘 폰트·이모지 없이 SVG(stroke 2.2)와 글리프만 썼는가
10. 서버가 주지 않는 값을 추측해서 표시하지 않았는가 (반경 · 등락 · 거리 · 남은 퀘스트 수)
11. 되돌릴 수 없는 동작(응원 · 거절 · 동료 해제)이 그렇게 보이는가
12. **360×800에서 넘치지 않는가** — 닉네임 같은 사용자 입력과 서버가 개수를 정하는 목록을 특히 확인한다
