# 11. 모션 — 무엇이 어디에 들어갔고 무엇을 확인해야 하나

> 관련 문서: `09-design-system.md` §3-1(규칙) · `10-motion-plan.md`(계획과 검증 방법)

자동 테스트로 고정한 것과 **사람이 기기에서 봐야만 하는 것**을 갈라 적는다.
`flutter test` 255개가 통과해도 아래 §3은 여전히 남는다 — 손에서 어떤지는 테스트가 모른다.

## 1. 어디에 무엇이 들어갔나

### 1-1. 앱 전체

| 무엇 | 어디 | 값 |
|---|---|---|
| 프레스 피드백 | `LqButton`(29개 파일) · `LqCard`(35개 파일, `onTap`이 있을 때만) · `LqChip`(8개 파일) · 하단 탭 5개 | 밝기 −25% + 섀도 `(1,1)`까지 축소 + 줄어든 만큼 내려앉음, 110ms |
| 페이지 전환 | 탭 밖 push 라우트 33개 | **플랫폼 기본** — Android `PredictiveBack`(제스처 없으면 `FadeForwards` 가로 25%·450ms), iOS Cupertino 슬라이드 |
| 탭 전환 | `navigation_shell.dart` `_BranchFade` | 불투명도 0.55→1 + 크기 0.99→1, 300ms |
| 축하 화면 전환 | `/quests/result` **하나만** | 겹쳐 흐리기(슬라이드 없음), 300ms |

### 1-2. 홈 (`home_screen.dart`)

| 무엇 | 값 |
|---|---|
| 섹션 순차 등장 | 5개(로고 · 인사 · 레벨 카드 · 오늘의 퀘스트 · 인증 광장), 40ms 간격 · 각 200ms |
| 캐릭터 패럴랙스 | 인사말 옆 캐릭터가 스크롤의 0.16배만큼 뒤처짐(최대 40px) |
| 끌어서 완료 | 퀘스트 행을 오른쪽으로 84px 끌면 완료. 최대 116px, 놓으면 스프링 정착 |
| 체크 버튼 | 완료 순간 원이 1.3배까지 부풀었다 가라앉음 + `+EXP`가 22px 떠오르며 사라짐 |
| 완료 후 이동 | 420ms 기다렸다 결과 화면으로 |
| EXP 진행 바 | (기존) 값이 바뀌면 500ms |

### 1-3. 퀘스트 완료 결과 (`quest_result_screen.dart`)

총 **1.6초** 시간표. 구간이 겹쳐 있다.

| 시점 | 무엇 |
|---|---|
| 0 ~ 22% | "퀘스트 완료!" 카드가 0.55배에서 튕기며 찍힘(바운스) |
| 0 ~ 30% | 떠다니는 종이조각 페이드 인 |
| 12 ~ 40% | 캐릭터가 34px 아래에서 올라옴 |
| 30 ~ 50% | 퀘스트 이름 |
| 40 ~ 78% | 보상 카드 — **EXP가 0부터 세어 올라감** |
| 62 ~ 88% | 레벨업 패널 · 도감 · 업적 · 인증 거리 |
| 78 ~ 100% | 하단 버튼 |
| 1.6초 후 | 레벨업 팝업 · 비밀 업적 모달 |

| 화면 | 무엇 |
|---|---|
| 마이페이지 | 레벨 숫자 · EXP 텍스트가 값이 바뀌면 겹쳐 흐리며 교체(300ms) |

## 2. 자동 테스트가 이미 고정한 것 — 다시 보지 않아도 된다

- 눌림 값·복귀·**드래그 이탈 시 취소**·비활성 무반응·탭 콜백 1회
- 커스텀 전환을 쓰는 라우트가 `/quests/result` **하나뿐**이라는 것, 테마에 플랫폼 빌더가 박혀 있다는 것
- 시간표 단계 순서, EXP가 중간에 최종값이 아니라는 것, 끝나면 전부 제자리
- 끌기가 손가락을 1:1로 따라오는 것, 상한, 임계값 판정, **되돌아가는 중 다시 잡기**
- 패럴랙스 계수·상한, 스크롤 뷰 밖에서 안전한 것
- Hero tag 중복 없음
- 동작 줄이기에서 전부 멈추고 `pumpAndSettle()`이 끝나는 것

## 3. 기기에서 사람이 봐야 하는 것

에뮬레이터가 아니라 **실기기**. 가능하면 저사양 안드로이드 1대를 포함한다.

```bash
cd app && fvm flutter run --profile
```

### 3-1. 네비게이션 제스처 — 최우선

전환 방식을 두 번 바꿨다(커스텀 → 플랫폼 기본). 여기가 깨지면 앱을 못 쓴다.

- [ ] **iOS**: 아무 push 화면(예: 마이 → 나의 기록 → LifeDex)에서 **왼쪽 가장자리를 스와이프해 뒤로** 가진다
- [ ] iOS: 스와이프를 반쯤 하다 놓으면 원래 화면으로 되돌아온다
- [ ] **Android 14+**: 뒤로 제스처를 시작하면 **이전 화면이 미리 보인다**(predictive back), 중간에 취소된다
- [ ] Android: 시스템 뒤로 버튼으로 정상 pop
- [ ] `/quests/result`에서 뒤로: 이 화면만 페이드다. 스와이프 백이 안 되는 것이 **의도된 동작**
- [ ] 전환 중에 연타해도 같은 화면이 두 번 쌓이지 않는다

### 3-2. 끌어서 완료 (홈)

세로 스크롤과 가로 끌기가 한 화면에서 싸운다. 테스트로 확인 불가능한 부분이다.

- [ ] 홈을 **세로로 스크롤할 때** 퀘스트 행이 옆으로 밀리지 않는다
- [ ] 대각선으로 애매하게 끌 때 스크롤과 끌기 중 하나만 일어난다
- [ ] 조금 끌다 놓으면 스프링으로 제자리(튕김이 과하지 않은지)
- [ ] 84px 넘겨 놓으면 완료 + **햅틱이 손에 느껴진다**
- [ ] 되돌아가는 중에 다시 잡으면 그 자리에서 이어진다
- [ ] **위치 퀘스트 행은 끌리지 않는다**(인증이 필요하므로)
- [ ] 만료·완료된 행도 끌리지 않는다
- [ ] 끌어서 완료했을 때와 체크 버튼으로 완료했을 때 결과가 같다

### 3-3. 완료 흐름

- [ ] 체크를 누르면 **그 자리에서** 원이 채워지고 `+EXP`가 떠오른다
- [ ] 그다음 결과 화면으로 넘어간다(420ms가 굼떠 보이지 않는지)
- [ ] 결과 화면 1.6초 연출이 순서대로 보인다 — 도장 → 캐릭터 → 이름 → EXP 카운트업 → 나머지 → 버튼
- [ ] **1.6초가 길지 않은지.** 퀘스트를 3~4개 연속 완료해 보고 지겨우면 줄인다
- [ ] 연출 도중 화면을 스크롤하거나 뒤로 가도 깨지지 않는다
- [ ] 레벨업이 있는 경우 팝업이 **연출 끝난 뒤에** 뜬다
- [ ] 목록을 나갔다 다시 열었을 때 완료 행들이 **다시 터지지 않는다**

### 3-4. 프레스 피드백

- [ ] 버튼·카드를 누르면 어두워지면서 살짝 내려앉는다(과하지 않은지)
- [ ] 목록을 빠르게 스크롤할 때 카드가 **눌린 채 남지 않는다**
- [ ] 하단 탭 연타 시 잔상·깜빡임 없음
- [ ] 비활성 버튼은 반응 없음

### 3-5. 홈 그 밖

- [ ] 홈 진입 시 섹션이 위에서부터 나타난다(총 0.4초 이내로 느껴지는지)
- [ ] 당김-새로고침 후 섹션이 **다시 날아오지 않는다**
- [ ] 스크롤할 때 캐릭터가 살짝 뒤처진다(떠다니는 것처럼 과하지 않은지)
- [ ] 탭을 옮겼다 홈으로 돌아올 때 스크롤 위치가 유지된다

### 3-6. 접근성

**실기기에서** iOS 설정 → 손쉬운 사용 → 동작 → 동작 줄이기 ON,
Android 개발자 옵션 → 애니메이션 배율 전부 off.

- [ ] 앱 전체를 한 바퀴 돌 때 멈추거나 깨지는 화면이 없다
- [ ] 떠다니는 장식·펄스 링이 **멈춰 있다**
- [ ] 완료 결과가 연출 없이 바로 보이고, 팝업도 바로 뜬다
- [ ] 끌어서 완료가 비활성이고 **체크 버튼으로는 완료된다**
- [ ] TalkBack/VoiceOver로 퀘스트 행에서 "완료" 사용자 정의 동작이 읽힌다

### 3-7. 성능

- [ ] 저사양 기기에서 홈 스크롤 시 프레임 저하 없음(패럴랙스가 매 프레임 다시 그린다)
- [ ] 완료 결과 화면에서 raster 16ms 초과 프레임이 튀지 않음
- [ ] 끌기 중 프레임이 손가락을 놓치지 않음

### 3-8. 통합 테스트 (기기 필요)

```bash
cd app && fvm flutter test integration_test/app_e2e_test.dart -d <device>
```

## 4. 알려진 한계 — 확인해도 안 되는 것

- **퀘스트 목록 화면에는 체크·끌기가 없다.** 그 화면의 행은 상세로 보내는 `›`만 있고, 완료는 홈과 상세에서만 한다. 끌기 연출은 **홈에서만** 보인다
- **캐릭터는 여전히 정적 PNG다.** 상태에 반응하는 캐릭터(Rive)는 에셋 제작자가 없어 넣지 않았다
- 긴 목록(퀘스트·친구·그룹)에는 순차 등장이 없다. `ListView`가 항목을 재활용해 스크롤할 때마다 다시 날아오기 때문이다
- 인증 광장 사진, 도감 항목에는 공유 요소(Hero)가 없다. 사진은 캐러셀이라 Hero가 지저분해지고, 도감은 이어질 대상 화면이 없다
